无人机病害导入

下载病害模板
请选择 Excel 文件（.xlsx）
与 Excel 一起导入。ZIP 内文件名用照片编号，例如 6759.jpg，与 Excel「照片编号」一致。支持子目录，支持 jpg/jpeg/png
导入规则：
  • Excel 与照片 ZIP 一次上传，按本批照片编号挂图（与 App 一样，不依赖库里旧编号是否重名）
  • 「缺损类型」填网页「病害类型」名称（如下拉里 # 后面那段，如麻面）；不要填「病害分组」，不要写成 5.1.1-1-2#麻面
  • 模板列出全部定量列。导入时只保留该缺损类型在网页上使用的列
  • 缺损位置写成「编号#名称」。没有同名构件时会新建，不改对象树上的构件数量
  • 参考面与网页一致，分三列：名称、起点(m)、终点(m)。终点可空
  • 是否参与评定、评定标度、发展趋势必填。不参与评定时标度留空，入库为 0
  • 面积标识下拉选：普通 / 平均 / 总计，空着按普通。一条病害对应一组定量数据
  • 请删除模板示例行后再导入
